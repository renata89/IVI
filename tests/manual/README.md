# IVI — Scenariusze testów manualnych

Plik `index.html` zawiera 30 scenariuszy testowych dla testerów.
Otwórz w przeglądarce, zaznaczaj wyniki.

## Jak używać

1. Otwórz `tests/manual/index.html` w przeglądarce
2. Wpisz swoje imię w polu Tester
3. Wykonuj kroki po kolei
4. Zaznacz **Pass** ✅ lub **Not Pass** ❌
5. Przy failu: wpisz komentarz + dodaj screena
6. Kliknij **Export** aby pobrać raport (.md)

## Wyniki

- Wyniki zapisują się w localStorage — nie giną po odświeżeniu
- **Reset** czyści wszystkie wyniki
- **Export** generuje plik markdown do wysłania/podejrzenia

## Kategorie testów

1. Dashboard
2. Kalendarz i konflikty
3. Notatki
4. Series i zobowiązania
5. Dokumenty
6. Push-to-Talk
7. Backend API
