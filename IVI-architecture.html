IVI Architecture

Meeting Assistant — System Architecture & Data Flow

Desktop App (Electron)

  • • System audio capture via desktopCapturer
  • • No meeting bot / API integration needed
  • • Secure context isolation (preload bridge)
  • • Cross-platform: macOS & Windows builds
  • • Tray-based background operation
  • • Push-to-talk hotkey (Cmd/Ctrl+Shift+I)

Python Backend (FastAPI)

  • • REST API + WebSocket (port 8765)
  • • Local Whisper/WhisperX transcription
  • • LLM summaries (OpenAI / Gemini / mock)
  • • Google Calendar sync (OAuth2)
  • • SQLite with WAL mode (local-first)
  • • Docker containerization ready

Key Differentiators

  • • Companion app — no bot needed
  • • All major meeting platforms supported
  • • Live AI suggestions during meetings
  • • Fully offline-capable (mock mode)
  • • Privacy-first: no cloud dependency
  • • Clean architecture, MIT licensed
